=== PROMPT 4: Database Migrations (Struktur Tabel) ===
Buatkan saya file Migration Laravel yang rapi dan terstruktur (dengan urutan yang benar agar tidak error foreign key) untuk 6 tabel berikut. Gunakan fitur Blueprint standar Laravel:

1. `chapters` (Data Basis/Wilayah): id, name, region_code (unique), leader_name, basecamp_address, is_active (boolean), timestamps.
2. Modifikasi tabel `users`: Tambahkan foreignId 'chapter_id' (nullable, constrained ke chapters), enum 'role' (super_admin, admin_chapter, member), enum 'status' (active, pending_approval, suspended).
3. `member_profiles` (Biodata Lengkap): foreignId 'user_id' (cascade delete), nia (unique, nullable), nik_ktp (unique, 16 char), place_of_birth, date_of_birth, gender (L/P), blood_type, address, phone_number, emergency_contact_name, emergency_contact_number, emergency_contact_relation, occupation, shirt_size, ktp_photo_path, profile_photo_path, joined_date, timestamps.
4. `nfc_cards` (Data Kartu Fisik): foreignId 'user_id' (cascade delete), uid_number (unique), enum 'card_vendor' (emoney, flazz, brizzi), enum 'status' (active, lost, blocked), issued_at (timestamp), timestamps.
5. `voluntary_dues` (Kas/Donasi): foreignId 'user_id', foreignId 'chapter_id', decimal 'amount', payment_proof_path, enum 'status', notes, timestamps.
6. `event_attendances` (Presensi Tap NFC): foreignId 'chapter_id', foreignId 'user_id', event_name, scanned_at (timestamp), timestamps.


=== PROMPT 5: Layout Dashboard & Menu Multi-Role ===
Buatkan saya kode untuk file layout dashboard utama `resources/views/layouts/app.blade.php` dan file view dashboard untuk 3 role berbeda menggunakan Tailwind CSS.

Spesifikasi `app.blade.php`:
Buat layout dengan struktur Sidebar di sebelah kiri (fixed) dan Topbar (dengan profil user) di atas. Sidebar ini harus dinamis menampilkan menu berdasarkan role user yang sedang login (gunakan directive @if(auth()->user()->role === '...')). Gunakan ikon SVG sederhana atau Heroicons untuk tiap menu.

Menu Sidebar untuk Role 'member' (Anggota):
1. Dashboard (Tampilkan visual KTA Digital & QR Code/Status NFC).
2. Profil Saya (Edit kelengkapan biodata).
3. Iuran & Kas Suka Rela (Form upload bukti transfer).
4. Lapor Kartu Darurat (Tombol untuk blokir NFC jika kartu hilang).

Menu Sidebar untuk Role 'admin_chapter' (Pengurus Wilayah):
1. Dashboard Chapter (Statistik anggota wilayah tersebut).
2. Verifikasi Anggota Baru (List pendaftar yang butuh di-approve KTP-nya).
3. Scan Presensi NFC (Halaman khusus berisi inputan untuk menangkap hasil scan dari HP NFC panitia saat nobar).

Menu Sidebar untuk Role 'super_admin' (Pusat):
1. Dashboard Utama (Grafik statistik anggota se-Indonesia).
2. Master Chapter (Tambah/Edit data basis wilayah).
3. Cetak & Aktivasi Kartu NFC (Form untuk menautkan UID kartu fisik baru ke akun anggota).
4. Broadcast Pengumuman (Kirim notifikasi ke seluruh anggota).

Tolong buatkan kode layout utamanya (`app.blade.php`) secara lengkap, dan berikan satu contoh desain view yang sangat rapi untuk `resources/views/dashboard/member/index.blade.php` (menampilkan UI Kartu Anggota Digital).
